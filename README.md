## 🚀 النشر على GitHub Pages

### الطريقة التلقائية (GitHub Actions)

1. ارفع الكود إلى GitHub:
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```

2. فعّل GitHub Pages من إعدادات الريبو:
   - اذهب إلى **Settings** → **Pages**
   - تحت **Source** اختر **GitHub Actions**

3. بعد رفع الكود، سيعمل الـ workflow تلقائياً وينشر الموقع على:
   ```
   https://USERNAME.github.io/REPO-NAME/
   ```

### الطريقة اليدوية

```bash
# تثبيت المكتبات
npm install

# بناء المشروع
npm run build

# مجلد dist يحتوي على الملفات الجاهزة للنشر
# ارفع محتويات dist إلى branch gh-pages
```
